# Wordpress bedrock boilerplate
A boilerplate which comes with a pre-configured WordPress bedrock installation.

## Changes compared to roots/bedrock repo
- Added development changes to .gitignore file (macOS, IDEs, etc)
- Added a starter theme to the themes folder
- Added plugins and repositories to composer.json

## Requirements
- A valid ACF PRO license key (if you want to use ACF PRO)
- Composer installed globally on your machine
